# CityVerse

CityVerse is a tourism website showcasing the cities of Butwal and Bhairahawa in Nepal. Explore famous spots, book transport, and discover what these vibrant cities have to offer.

## Features

- **Attractions**: Browse famous spots including Manimukunda Park, Butwal Hill Park, Devdaha, Buddha Park, and more
- **Transport Booking**: Book bikes, buses, cars, and e-rickshaws between locations
- **Dark Mode**: Toggle between light and dark themes
- **Responsive Design**: Works seamlessly on desktop and mobile devices
- **Interactive UI**: Smooth animations and user-friendly interface

## Destinations

### Butwal
- Butwal City Center
- Manimukunda Park
- Butwal Hill Park
- Siddhartha Chowk

### Bhairahawa
- Bhairahawa (Siddharthanagar)
- Buddha Park
- Nearby attractions

### Around
- Devdaha (12 km from Butwal) - Historical Buddhist site

## Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Styling**: Custom CSS with CSS variables
- **Icons**: Boxicons
- **Animations**: ScrollReveal.js
- **Filtering**: Isotope.js

## Getting Started

1. Clone the repository
```bash
git clone https://github.com/Auralith-Bit/CityVerse.git
cd CityVerse
```

2. Open `frontend/index.html` in your browser, or serve with a local server
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve frontend
```

3. Navigate to `http://localhost:8000`
